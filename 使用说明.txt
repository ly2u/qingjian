轻笺 · 轻量 Markdown 编辑器

双击“轻笺.exe”启动。程序不需要安装，不需要 Node.js，也不需要登录。
移动或分享程序时，请保留整个文件夹；也可以分享“轻笺-Windows-x64.zip”。

日常使用
  Ctrl+O       打开 Markdown / 文本文件
  Ctrl+N       新建文档
  Ctrl+S       首次选择保存位置 / 立即保存
  Ctrl+Shift+S 另存为
  Ctrl+1/2/3   编辑 / 左右对照 / 预览
  Ctrl+4       实时编辑，点击段落展开源码
  Esc          在实时模式中收起源码，恢复排版
  Ctrl+F/H     查找 / 替换
  Ctrl+B/I/K   粗体 / 斜体 / 链接
  Ctrl+Z/Y     撤销 / 重做
  Ctrl+Shift+F 专注写作
  Ctrl+Shift+O 显示 / 收起目录
  Ctrl+W       关闭当前文档
  Ctrl+P       打印，也可选择“另存为 PDF”

你也可以拖入 .md 文件，通过左栏打开文件夹，用目录跳转章节。
对照视图支持双向同步滚动；拖动中线可以调整栏宽，双击中线恢复各半。
支持浅色与深色主题、表格、任务列表、常见代码高亮和 [[文档名]] 本地链接。
对照模式下，点击左侧会高亮右侧对应内容；点击右侧会定位并高亮左侧。
段落、表格行和列表条目分别对应，公式与图表按整块对应。

目录（大纲）
  点击顶部“目录”或按 Ctrl+Shift+O 显示、收起目录；左侧也可切换“文档 / 目录”。
  拖动左侧栏右边界调整宽度，松开后自动记住；双击边界恢复默认宽度。
  标题以缩进表示层级，不额外显示 H1、H2 标记。长标题可悬停查看全文。
  根据 # 到 ###### 标题自动生成层级，支持点击跳转、折叠子章节和全部展开 / 收起。
  当前编辑或阅读的章节会高亮，标题修改和外部文件更新会自动反映到目录。
  编辑、对照、实时、预览四种视图均可使用；对照跳转会同时定位两侧。
  会记住上次选择的侧栏视图；没有标题时会显示 Markdown 标题写法提示。

实时编辑
  选择顶部“实时”或按 Ctrl+4，未编辑的内容会显示排版效果。
  点击段落或列表条目可展开 Markdown 源码，切到别处后恢复排版。
  表格、代码、独立公式和 Mermaid 按整块展开。
  Esc 恢复排版，Ctrl+单击链接可跳转。任务框可以直接勾选。
  与其他视图共用一份 Markdown，保留撤销重做、查找替换和草稿恢复。

数学公式与 Mermaid
  行内公式：$E=mc^2$，或 \(E=mc^2\)
  独立公式：用 $$ 和 $$ 包住公式，也可使用 \[ 和 \]。
  图表：用 ```mermaid 开始代码块，以 ``` 结束。
  支持流程图、时序图、甘特图、类图等。两种渲染均为离线运行、按需加载。
  公式使用 KaTeX，支持常用 LaTeX 数学语法，不提供完整 LaTeX 文档编译。
  HTML 导出会包含公式字体与已渲染图表，无需接收方安装渲染组件。

Windows 默认打开方式与移除
  更多选项 → Windows 文件关联 → 注册到打开方式 → 选择默认应用。
  也可以双击“注册到打开方式.cmd”，再通过 Windows 的“打开方式”选择轻笺。
  支持 .md、.markdown、.mdown；注册只对当前用户生效，无需管理员权限。
  更新版本时，直接在新版点击“替换旧版注册”，或运行新版的注册脚本。
  旧版的打开路径、图标和卸载入口会自动替换，无需先移除旧注册。
  原来选择轻笺的默认打开方式可沿用，其他应用的默认选择不变。
  移除时，点“移除系统注册”或双击“移除系统注册.cmd”。
  Windows“已安装的应用”中也有“轻笺（便携版系统注册）”移除入口。
  移除只清理轻笺的系统注册，保留程序、文档、图片和草稿。
  卸载当前注册的版本时，请先移除注册，再删除程序文件夹。
  更新注册后，可直接删除旧程序目录。
  若轻笺曾是默认应用，移除后请重新选择 .md 的打开方式。
  移动程序目录后请重新注册。

草稿与文件
  已打开或保存到磁盘的文档，在输入停顿约 0.7 秒后自动写回原文件。
  持续输入时约每 2 秒补存，切换文档、窗口失去焦点和退出前也会尝试补存。
  未命名文档首次按 Ctrl+S 选择文件位置，之后自动保存；Ctrl+S 可立即保存。
  另外保留本地恢复草稿，重启后恢复打开的文档。
  其他程序或同步软件修改了源文件时，已打开的标签与预览会自动刷新。
  本地与外部同时有修改时暂停自动保存，点击提示条“查看并处理”对照两份内容。
  选择使用外部版本时，本地编辑会另留为“本地冲突副本”草稿，不会直接丢弃。
  源文件被删除或移走时保留当前内容，可重新创建文件或另存为。
  文件暂时被占用或无法访问时会自动重试，也可点击“重试”。
  保存原文件时保留识别到的字符编码与换行格式。
  插入图片前先保存文档。图片会复制到文档旁的 assets 文件夹。
  导出的 HTML 会嵌入本地图片，便于单独分享；网络图片仍需联网显示。

运行环境与数据位置
  适用于 Windows 10/11 64 位，需要 .NET Framework 4.7.2 或更高版本，
  以及 Microsoft Edge WebView2 Evergreen Runtime。
  本机已具备运行环境；其他电脑若缺少 WebView2，请从微软官网下载：
  https://developer.microsoft.com/microsoft-edge/webview2/
  程序文件夹不包含浏览器内核，使用系统 WebView2。
  草稿、设置和 WebView2 缓存保存在 %LOCALAPPDATA%\Qingjian。
  轻笺不提供云存储或同步传输服务。可把文档放在 OneDrive、Syncthing 等同步文件夹，
  由这些工具负责多端传输，轻笺负责自动读写与外部修改刷新。
  文档中的网络图片和外部链接仍会访问网络。

当前范围
  优先支持常用 Markdown、公式和图表，暂未加入插件系统。
  单个文本文件上限 16 MB。文件夹列表最多显示 3,000 个文件、扫描 8 层子目录。
  同步软件实际传输完成后才会读取到新内容；同时编辑产生的冲突需要手动选择版本。
