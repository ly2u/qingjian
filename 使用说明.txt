轻笺 · 轻量 Markdown 编辑器

双击“轻笺.exe”启动。程序不需要安装，不需要 Node.js，也不需要登录。
移动或分享程序时，请保留整个文件夹；也可以分享“轻笺-Windows-x64.zip”。

日常使用
  Ctrl+O       打开 Markdown / 文本文件
  Ctrl+N       新建文档
  Ctrl+S       保存到文件
  Ctrl+Shift+S 另存为
  Ctrl+1/2/3   编辑 / 左右对照 / 预览
  Ctrl+F/H     查找 / 替换
  Ctrl+B/I/K   粗体 / 斜体 / 链接
  Ctrl+Z/Y     撤销 / 重做
  Ctrl+Shift+F 专注写作
  Ctrl+W       关闭当前文档
  Ctrl+P       打印，也可选择“另存为 PDF”

你也可以拖入 .md 文件，通过左栏打开文件夹，用大纲跳转章节。
对照视图支持双向同步滚动；拖动中线可以调整栏宽，双击中线恢复各半。
支持浅色与深色主题、表格、任务列表、常见代码高亮和 [[文档名]] 本地链接。
对照模式下，点击左侧会高亮右侧对应内容；点击右侧会定位并高亮左侧。
段落、表格行和列表条目分别对应，公式与图表按整块对应。

数学公式与 Mermaid
  行内公式：$E=mc^2$，或 \(E=mc^2\)
  独立公式：用 $$ 和 $$ 包住公式，也可使用 \[ 和 \]。
  图表：用 ```mermaid 开始代码块，以 ``` 结束。
  支持流程图、时序图、甘特图、类图等。两种渲染均为离线运行、按需加载。
  公式使用 KaTeX，支持常用 LaTeX 数学语法，不提供完整 LaTeX 文档编译。
  HTML 导出会包含公式字体与已渲染图表，无需接收方安装渲染组件。

Windows 默认打开方式与移除
  更多选项 → Windows 文件关联 → 注册到打开方式 → 选择默认应用。
  也可以双击“注册到打开方式.cmd”，再通过 Windows 的“打开方式”选择轻笺。
  支持 .md、.markdown、.mdown；注册只对当前用户生效，无需管理员权限。
  移除时，点“移除系统注册”或双击“移除系统注册.cmd”。
  Windows“已安装的应用”中也有“轻笺（便携版系统注册）”移除入口。
  移除只清理轻笺的系统注册，保留程序、文档、图片和草稿。
  如需删除程序，请先移除注册，再删除程序文件夹。
  若轻笺曾是默认应用，移除后请重新选择 .md 的打开方式。
  移动程序目录后请重新注册。

草稿与文件
  修改约 0.65 秒后自动保留为本地草稿，重启后恢复打开的文档。
  自动保留草稿不会写回原文件；请按 Ctrl+S 保存到文件。
  检测到其他程序改过原文件时，会在覆盖前询问。
  保存原文件时保留识别到的字符编码与换行格式。
  插入图片前先保存文档。图片会复制到文档旁的 assets 文件夹。
  导出的 HTML 会嵌入本地图片，便于单独分享；网络图片仍需联网显示。

运行环境与数据位置
  适用于 Windows 10/11 64 位，需要 .NET Framework 4.7.2 或更高版本，
  以及 Microsoft Edge WebView2 Evergreen Runtime。
  本机已具备运行环境；其他电脑若缺少 WebView2，请从微软官网下载：
  https://developer.microsoft.com/microsoft-edge/webview2/
  程序文件夹不包含浏览器内核，使用系统 WebView2。
  草稿、设置和 WebView2 缓存保存在 %LOCALAPPDATA%\Qingjian。
  不上传文档，不使用云同步。文档中的网络图片和外部链接仍会访问网络。

当前范围
  优先支持常用 Markdown、公式和图表，暂未加入插件系统。
  单个文本文件上限 16 MB。文件夹列表最多显示 3,000 个文件、扫描 8 层子目录。
  已打开文件被外部修改后，需要关闭该标签并重新打开才能载入新内容。
